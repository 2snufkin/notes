# What is FlexBox
Flexbox, short for **Flexible Box Layout**, is a powerful layout model in CSS that allows for efficient arrangement and distribution of elements (flex items) within a container (flex container). It simplifies the process of designing layouts, especially for dynamic content with unknown sizes.
- **Flex Container**: A parent element designated with `display: flex;` which contains flex items.
- **Flex Items**: The child elements within the flex container that can grow or shrink based on the available space.
## Key Features of Flexbox

- **Simplifies Layout Management**: Before Flexbox, developers relied on the float property to create layouts, which required precise calculations and often led to complications like clearing floats. Flexbox streamlines this process significantly.

- **One-Dimensional Model**: Flexbox focuses on arranging items in either rows or columns, making it a one-dimensional layout model. In contrast, CSS Grid is a two-dimensional layout model that will be discussed later.

- **Flex Containers and Items**: Understanding the relationship between flex containers (the parent element) and flex items (the child elements) is crucial for utilizing Flexbox effectively.

- A class with `display: flex` automatically arranges its children side by side if it's set up as a row. If changed back to `block`, items revert to stacking vertically.

## Structure of Flexbox

- **Default Orientation**: By default, Flexbox arranges items in a row (horizontal). To create a flex container, set the `display` property to `flex` on an element (like a `<div>` or `<ul>`).

- **Axes**:
  - **Main Axis**: The primary axis along which flex items are arranged.
    - For rows, this is horizontal.
    - For columns, this becomes vertical.
  - **Cross Axis**: The perpendicular axis to the main axis.
    - For rows, this is vertical.
    - For columns, it is horizontal.

### Changing Direction

To switch from a row layout to a column layout:
- Set the `flex-direction` property to `column`. This will change how items are displayed:
  - Main axis becomes vertical.
  - Cross axis becomes horizontal.

  


# Flexbox Container 
All the properties mentioned here: `display:flex`, `flex-wrap`, `flex-direction` should be defined in the container element.
## Creating a Flex Container
To set up a flex container:
- Use a `<div>` (or any HTML element) with a class name, such as `flex-container`.
- Inside this container, add flex items, which can be any HTML elements like `<div>`, `<p>`, or `<ul>`.

### Example Structure

```html
<div class="flex-container">
    <div class="flex-item">Item 1</div>
    <div class="flex-item">Item 2</div>
    <div class="flex-item">Item 3</div>
</div>
```


## Setting Up Flex Display
To enable Flexbox on the container:

- Set `display: flex;` on the `.flex-container`. This arranges all direct children (flex items) in a row by default.
- **Flex Items**: Only direct children of the flex container are considered flex items.
- If you nest elements inside a flex item, they do not become separate flex items.

## Changing Flex Direction

You can change the direction of the flex items using `flex-direction`:
- Default is `row`.
- To stack items vertically, use:
  
  ```css
  .flex-container {
      flex-direction: column;
  }
  ```

- **Column Reverse**: Places the last item at the top.
  
```css
.flex-container {
    flex-direction: column-reverse;
}
```
- **Row Reverse**: Starts from the last item and moves leftward.

```css
.flex-container {
    flex-direction: row-reverse;
}
```

## Handling Overflow with Flex Wrap

To control how overflowed items behave:
- Set `flex-wrap` to allow wrapping onto new lines when necessary:
- If not set, all the flex items may shrink to fit the row
- If set, each item will keep its size and when there is no more space for an item it will jump to the next line.
- Using `flex-wrap` allows your layout to adapt responsively, especially on smaller screens. 

```css
.flex-container {
    flex-wrap: wrap; /* Default is nowrap */
}
```



## Managing Gaps Between Items
- Instead of adding margins directly to each item for spacing, you can use:

```css
.flex-container {
    gap: 10px; /* Applies space both horizontally and vertically */
}
```
- You can specify gaps individually as well:

```css
.row-gap { 
   row-gap: 10px; /* Space between rows */
}

.column-gap { 
   column-gap: 10px; /* Space between columns */
}
```


# Align & Justify Items

## Container's properties
This section focuses on two key properties used for aligning flex items: **justify-content** and **align-items**. 

### Main Axis vs Cross Axis
- The **main axis** refers to the primary direction in which flex items are laid out, while the **cross axis** runs perpendicular to this.
- In a **row**, the main axis is horizontal, and the cross axis is vertical.
- In a **column**, the main axis is vertical, and the cross axis is horizontal.

### Justify Content
The `justify-content` property aligns flex items along the main axis:
- **Row (Horizontal Main Axis)**:
  - `flex-start`: Aligns items to the left (default).
  - `flex-end`: Aligns items to the right.
  - `center`: Centers items horizontally.
  - `space-between`: Distributes space between items; no space at ends.
  - `space-around`: Spaces out items with equal space around them.
  - `space-evenly`: Distributes space evenly between and around items.

### Align Items
The `align-items` property aligns flex items along the cross axis:
- **Row (Vertical Cross Axis)**:
  - `flex-start`: Aligns items to the top.
  - `flex-end`: Aligns items to the bottom.
  - `center`: Centers items vertically.
  - `stretch`: Stretches items to fill available height (default behavior).
  - `baseline`: Aligns item baselines.

## Switching Directions
When changing from row to column:
- The role of each property shifts:
  - **Justify content** now aligns vertically (main axis).
  - **Align items** now aligns horizontally (cross axis).


## Individual Item Alignment
To align specific flex items differently than others, use:
- **Align Self**: This property can be applied directly to individual flex items. For example:

```css
.item2 {
    align-self: flex-end; /* Moves only this item */
}
```


# Flex Properties & Dynamic Sizing
Using key properties of Flexbox:
- `flex-grow`,
- `flex-shrink`
-  `flex-basis`
you can create flexible layouts that respond seamlessly to different screen sizes. Combining these properties into the shorthand form of `flex` simplifies your CSS while maintaining clarity in your layout design.

## Key Flexbox Properties

### Flex Shrink

- **Definition**: Controls how much a flex item will shrink relative to other items when the container is too small.
- **Default Value**: `1` (all items shrink equally).
  
#### Usage Example:
```css
.item-1 {
    flex-shrink: 0; /* Will not shrink */
}
```

### Flex Grow

- **Definition**: Specifies how much a flex item will grow relative to others when there’s extra space in the container.
- **Default Value**: `0` (items do not grow).

#### Usage Example:
```css
.item-1 {
    flex-grow: 1; /* Will take up remaining space */
}
```

### Flex Basis

- **Definition**: Sets the initial size of a flex item before space distribution occurs.
  
#### Usage Example:
```css
.item-3 {
    flex-basis: 200px; /* Starts at 200 pixels */
}
```

### Combined Property - Flex

The three properties (`flex-grow`, `flex-shrink`, and `flex-basis`) can be combined into one shorthand property called `flex`.

#### Shorthand Example:
```css
.flex-item {
    flex: 1 0 200px; /* Grow = 1, Shrink = 0, Basis = 200px */
}
```

## Practical Application

- To create evenly sized items across a container:

```css
.flex-item {
   flex: 1; /* All items grow and shrink equally */
}
```


- You can customize individual items by adjusting their `flex` values:

```css
.item-2 {
   flex: 2; /* Takes up more space than others */
}

.item-3 {
   flex: 2; /* Slightly larger than .item-1 but smaller than .item-2 */
}
```


# Flex Order
Beneficial when you want your content (e.g., paragraphs and images) displayed differently from how it appears in your markup.


- The `order` property allows you to specify the order of flex items.
- By default, all items have an order value of `0`. Items are displayed based on their order values (lower values appear first).
- For reversing use `flex-direction`.
